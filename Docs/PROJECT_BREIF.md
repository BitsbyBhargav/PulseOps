# PulseOps Analytics
## Predictive Maintenance Intelligence System
### Adani Ports and SEZ Ltd. — Hazira, Surat

---

## Overview
Port equipment failures cost crores per hour
in lost operations. PulseOps Analytics is a
predictive maintenance intelligence system that
analyzes equipment sensor data to predict
failures before they occur — shifting operations
from reactive to predictive maintenance.

---

## Business Problem
Unplanned equipment downtime at port facilities:
→ Crane failure = ₹50L–₹2Cr lost per day
→ Conveyor breakdown = cargo pile-up + delays
→ Vehicle failure = logistics chain disruption

Current state: Reactive maintenance
Target state:  Predictive maintenance

---

## Objective
Build an end-to-end analytics system that:
1. Ingests equipment sensor readings
2. Identifies failure patterns
3. Scores each equipment's risk level
4. Predicts failure within next 7 days
5. Presents insights to operations management

---

## Dataset
Primary:   UCI AI4I 2020 Predictive Maintenance
           10,000 records | 14 features | 5 failure types
Secondary: Synthetic port equipment data
           (Python-generated, Adani context)
